# Inleiding programmeren

C exercises from the introduction to programming course.

| Folder | What it is |
|---|---|
| `opdracht_week1` | First programs: reading input with `scanf`, some maths, a guessing game |
| `opdracht_week2` | Functions for exploring the Collatz sequence |
| `opdracht_week3` | Conway's Game of Life |
| `opdracht3` | Game of Life with start patterns, a printed grid and generations (plus tests) |
| `opdracht4` | Caesar and Vigenere ciphers, and code to crack them |
| `opdracht5` | DNA matcher with a small database, using the Levenshtein distance |
| `opdracht6_deel1`, `tarball` | First part of the grid game (`rooster` and `spel`) |
| `opdracht6_deel2` | Full grid game drawn with ncurses |
| `groeiende_array.c` | Growing an array with `malloc` |

Each folder with a `Makefile` can be built with `make`. `opdracht6_deel2` needs the ncurses library.
